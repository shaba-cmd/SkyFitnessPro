# SkyFitnessPro

Онлайн-тренировки для занятий дома: каталог курсов, авторизация, личный кабинет, видео-тренировки и учёт прогресса.

**Демо:** [SkyFitnessPro](https://sky-fitness-pro-henna.vercel.app/)

## Стек
React 19, TypeScript, React Router, CSS-модули, Vite, Jest + React Testing Library, ESLint, Prettier.
Архитектура — Feature-Sliced Design (FSD).

## Запуск
```bash
npm install
npm run dev      # dev-сервер
npm test         # тесты
npm run build    # сборка
```
Переменная окружения: `VITE_API_URL=https://wedev-api.sky.pro/api/fitness`
